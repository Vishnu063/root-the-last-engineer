# Nexus key art

Original key art generated for ROOT using the built-in image-generation tool. Used on the title and chapter story screens. Gameplay environments and characters are drawn with Canvas code in `world.js`.

Project asset: `assets/nexus-art.svg` contains an embedded optimized JPEG, avoiding an external image host. It is a raster illustration inside an SVG wrapper, not vector artwork.

Generation prompt:

> Use case: stylized-concept. Asset type: original landscape title-screen artwork for the browser adventure ROOT — The Last Engineer. A beautiful abandoned futuristic digital city at night, floating architectural districts linked by slender illuminated bridges, one small lone engineer in a hooded teal maintenance jacket on a foreground platform and a friendly small floating cube robot beside them. Towering central data citadel in the right distance, warm amber workshop light, cyan mint signal beam, subtle rain and mist, deep navy atmosphere, intricate clean handcrafted 3D game environment art, cinematic high quality lighting, hopeful mood. Wide landscape composition: left third mostly dark atmospheric negative space for HTML title, main city focal point on right two thirds. No text, no logos, no watermarks. Deliver an image usable as a local game background asset.

The illustration is environmental concept art, not a screenshot of playable game mechanics. No video is included; story transitions use this art with text and optional synthesized sounds.
